# Обяви в Пловдив

Всеки ден GitHub Actions брои обявите в imot.bg за Пловдив (Център и Сточна гара) и записва бройките в `history.csv`.
Графиката е в `docs/index.html` и се публикува чрез GitHub Pages.

- Офиси и магазини: продажба и наем
- Двустайни, тристайни и мезонети: продажба

Ръчно пускане: Actions → Daily count → Run workflow.
